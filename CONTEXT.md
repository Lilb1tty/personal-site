# Personal Portfolio

A recruiter-focused personal website that presents the owner's experience and selected work, with supporting professional profiles.

## Language

**Portfolio**:
An English-first, recruiter-focused personal website with a switch to Chinese, structured to help recruiters assess the owner as a candidate.
_Avoid_: Personal website, homepage

**Recruiter**:
The primary visitor evaluating the owner for an employment opportunity.
_Avoid_: Customer, client

**Java Developer**:
The owner's target role, emphasizing Java backend development and production delivery.
_Avoid_: Full-stack developer

**Vue 3 Capability**:
The owner's ability to independently make frontend adjustments in Vue 3 while remaining backend-focused.
_Avoid_: Frontend specialization

**Portfolio Stack**:
React with Vite and shadcn/ui, selected for the Portfolio's implementation.
_Avoid_: Vue 3 implementation

**Featured Case Study**:
A concise public presentation of a representative delivery project: CHI Billing, Weight & Balance, or Tanzania Booking & Settlement. Employer and client names may be shown.
_Avoid_: Project card, work sample

**Minimal Masthead**:
The opening Portfolio section, limited to the owner's name, Java Developer role, and profile links, with no promotional headline or hero visual.
_Avoid_: Hero section

**Profile Links**:
The owner's LinkedIn profile and overall GitHub profile, where GitHub serves as proof of work rather than links to individual repositories.
_Avoid_: Social links

**Contact Route**:
The owner's public email and LinkedIn profile, through which a recruiter can contact the owner.
_Avoid_: Résumé download, contact form

**Public Details**:
The Portfolio shows the owner's name, role, email, LinkedIn, and GitHub only. It does not show age, phone number, location, or a résumé download.
_Avoid_: Résumé details, personal profile
